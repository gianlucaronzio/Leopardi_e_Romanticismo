# Leopardi e il Romanticismo

Presentazione di 10 slide per la classe quinta liceo, a cura del Prof. G. Ronzio.

Contenuto: i tre poli culturali (Illuminismo, Classicismo, Romanticismo europeo), la polemica classico-romantica, il «classicismo romantico», la preferenza per la lirica, la distanza filosofica, le affinità con i romantici, la svolta del 1824 e le differenze con i romantici europei.

## Uso

- Frecce destra/sinistra, barra spaziale o swipe per scorrere
- `F` per lo schermo intero
- Stampa del browser: una slide per pagina

## Pubblicazione su GitHub Pages

1. Copiare `index.html`, `README.md` e `_config.yml` in una cartella del repository `gianlucaronzio/Repository` (ad esempio `leopardi-romanticismo/`)
2. Fare commit e push
3. Con Pages attivo (Settings, Pages, branch `main`), la presentazione è raggiungibile a `https://gianlucaronzio.github.io/Repository/leopardi-romanticismo/`

Nessuna dipendenza oltre ai font Google (Cinzel, Lora).
